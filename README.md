# SCrip

**Настольный плеер для SoundCloud · версия 1.0.0**

Прежний SoundCloud Desktop работал на Electron. Новая версия написана на C++20 и Qt Quick. Войдите в SoundCloud, чтобы слушать любимые треки, находить исполнителей и собирать собственные плейлисты.

[Скачать для Windows и Linux](https://github.com/sykia/SCrip/releases/tag/v1.0.0) · [Что изменилось](release-notes/1.0.0.md) · [Плагины](docs/plugins.md)

![Главная страница SCrip со станциями и персональными миксами](docs/screenshots/home.png)

## Установка

| Система | Как запустить |
| --- | --- |
| Windows 10 и 11, x64 | Скачайте и откройте установщик EXE |
| Debian 13, x86-64 | `sudo apt install ./SCrip-1.0.0-debian13-amd64.deb` |
| Arch Linux, x86-64 | `sudo pacman -U ./scrip-1.0.0-1-x86_64.pkg.tar.zst` |

Закройте окно, чтобы оставить музыку играть в фоне. Из меню значка SCrip в трее можно вернуть окно, переключить трек, поставить лайк или выйти. Для фонового режима нужна панель с системным треем.

![Любимые треки в SCrip](docs/screenshots/library.png)

## Что есть на главной

| Раздел | Откуда берётся музыка |
| --- | --- |
| Микс любимых | Последние добавленные в избранное треки |
| Новые релизы | Недавние публикации исполнителей из подписок |
| Вам может понравиться | Похожие треки по одному из ваших любимых |
| Микс открытий | Очередь из этих похожих треков |
| Слушать снова | Недавняя история прослушивания |

Нажмите на обложку, чтобы начать воспроизведение с выбранного трека.
Обложка микса запускает всю подборку, а строка справа — выбранный трек. Главная показывает разделы,
для которых SoundCloud вернул музыку. Обновить подборки можно внизу страницы.

## Оформление и прокрутка

В **Настройки → Форма и движение** можно отдельно менять скругление обложек,
аватаров и панелей. Изменения сразу видны в окне и сохраняются между запусками.
Для анимаций страниц, появления обложек и плавной прокрутки мышью доступны
выключатель и длительность от 120 до 500 мс.

Следующая страница медиатеки загружается при приближении к концу списка.
Если отключить автоподгрузку, появится кнопка «Загрузить ещё».

## Возможности

- Вход через официальный экран SoundCloud в отдельном окне браузера.
- Восстановление сессии, обновление токенов и отключение приложения от аккаунта.
- Поиск треков и плейлистов, избранное, лента подписок, история и свои треки.
- Просмотр плейлистов и создание приватного плейлиста с текущим треком.
- Потоковое воспроизведение, перемотка, громкость, очередь, повтор и перемешивание.
- Добавление/удаление избранного в режиме списка. Данные изменяются только после
  успешного ответа SoundCloud.

## Сборка и запуск

Нужны Qt 6.5+ (Quick, Network, Multimedia; Test для проверок), CMake 3.21+,
Ninja и компилятор C++20. Qt Multimedia должен включать backend с поддержкой HLS.

```sh
cmake --preset debug
cmake --build --preset debug
ctest --test-dir build/debug --output-on-failure
./build/debug/scrip
```

Для сборки без тестов: `cmake --preset debug -DBUILD_TESTING=OFF`.
На Windows x64 откройте `SCrip-Setup-x64.exe` и нажмите **Установить**.
Установка выполняется для текущего пользователя. Для тихой установки используйте
`SCrip-Setup-x64.exe /S`. Закройте работающий SCrip перед обновлением.
Удаление доступно в разделе установленных приложений Windows.

Для упаковки подготовьте отдельный каталог с релизным SCrip.exe, библиотеками
Qt, QML и медиабэкендом через windeployqt с параметром `--qmldir qml`.
Затем выполните `python packaging/windows/package.py <каталог> build/SCrip-Setup-x64.exe`
с NSIS 3 в PATH.

## Первое подключение

Нажмите «Войти в SoundCloud» и подтвердите доступ в браузере. SCrip принимает
ответ на локальном адресе и обменивает код через опубликованный Cloudflare Worker.
Пользователям публичной сборки не требуется регистрировать приложение или вводить ключи.

Для разработки со своим приложением задайте `SCRIP_AUTH_MODE=local`,
`SOUNDCLOUD_CLIENT_ID` и `SOUNDCLOUD_CLIENT_SECRET`. Зарегистрируйте в SoundCloud
адрес возврата `http://127.0.0.1:43821/callback`.

Адрес возврата не нужно открывать вручную. Пароль аккаунта, Google-вход и
дополнительные проверки обрабатывает сам SoundCloud. На Linux используется
отдельное окно установленного Firefox; для Chromium также предусмотрено новое
окно. Если поддерживаемый браузер не найден, открывается системный браузер.

Сессия сохраняется между запусками. Настройки → «Выйти из аккаунта» отзывает
доступ приложения через API и удаляет локальную сессию после подтверждения сервера.

Секреты и ограничения личного режима: [подключение и хранение данных](docs/soundcloud-security.md).


## Плагины

Откройте **Настройки → Плагины**, установите JSON-файл и включите расширение. [Пример «Студия»](examples/plugins/studio.json) меняет оформление обложек и добавляет быстрые переходы на главную. [Руководство по созданию плагинов](docs/plugins.md) описывает формат, доступные действия и ограничения доступа.
