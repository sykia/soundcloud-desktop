# SoundCloud Desktop 0.5.1

Исправлен случай, когда в настройках выбран русский язык, а SoundCloud продолжает показывать испанские или другие иностранные надписи. При включённом русском приложение приводит исходный язык сайта к английскому, после чего применяет русский словарь. При смене языка страница обновляется один раз.

### Установка

Если приложение уже установлено, откройте уведомление об обновлении или выберите «Проверить обновления» в меню значка в трее. Для первой установки скачайте `.exe` для Windows либо подходящий пакет Linux ниже на странице релиза.
