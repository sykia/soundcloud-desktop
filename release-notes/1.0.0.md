# SCrip 1.0.0

SoundCloud Desktop начинался как оболочка на Electron. В SCrip 1.0.0 плеер и медиатека переписаны на C++ и Qt Quick и работают через SoundCloud API.

![Главная SCrip](https://raw.githubusercontent.com/sykia/SCrip/v1.0.0/docs/screenshots/home.png)

- **На главной** — персональные миксы, станции исполнителей и новые релизы.
- **В очереди** — перетаскивание треков и команда «Играть следующим».
- **В трее** — пауза, переключение треков, лайк и возврат в окно. Чтобы завершить приложение, выберите «Выход».
- **В настройках** — свои темы, форма обложек и плагины.

### Скачать

**Windows 10/11 x64:** запустите установщик EXE. **Debian 13 x86-64:** установите пакет DEB. **Arch Linux x86-64:** установите пакет `.pkg.tar.zst`. При первом запуске войдите через официальный экран SoundCloud.
