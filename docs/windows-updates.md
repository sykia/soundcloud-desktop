# Обновления Windows

В установленной NSIS-сборке приложение проверяет GitHub Releases через
15 секунд после запуска и затем каждые 6 часов. Ручная проверка доступна
в cusade и меню трея. В запуске из исходников автообновление отключено.

Найденная версия загружается автоматически в штатный кэш electron-updater.
Прогресс и ошибки доступны в карточке обновления; неудачную загрузку можно
повторить. Закрытие карточки откладывает установку. Обычный выход из
приложения и завершение Windows не запускают установщик.

Только кнопка «Перезапустить и обновить» вызывает
`quitAndInstall(true, true)` — API закреплённого electron-updater 6.8.10.
NSIS обновляет существующую установку без мастера и запускает приложение.
Настройки, cookies и Insights находятся в userData вне каталога программы.
Удаление пользовательских данных в настройках NSIS явно отключено.
Установка для всех пользователей может потребовать UAC.

Это не горячая замена выполняемых файлов: Electron закрывается для
применения версии. Дифференциальная загрузка использует blockmap и старый
кэш установщика; при отсутствии подходящего кэша или недоступности range
requests библиотека скачивает полный пакет. Размер экономии не гарантирован.
На следующем запуске повторная проверка позволяет библиотеке найти и
проверить уже скачанный пакет, а не полагаться на сохранённый флаг «готово».

Целостность загрузки проверяется штатным механизмом electron-updater по
метаданным релиза. Проверка Authenticode зависит от настройки сертификата
и publisherName в сборке; один SHA512 не заменяет подпись издателя.
Нельзя отключать проверку подписи ради обхода ошибки обновления.

Релиз должен содержать согласованные установщик, `.exe.blockmap` и файл
канала обновлений (обычно `latest.yml`). Blockmap публикуется вместе с
установщиком. Stable-клиенты не переключаются автоматически
на prerelease; понижение версии запрещено.

Проверки: `npm run check`, `npm test`, `npm run test:ui`,
`npm run dist:win` (скрипт уже содержит `--publish never`). Тесты контроллера используют подмену
updater и проверяют загрузку, повтор после ошибки, обработку ошибки
установки, отсутствие установки без явного действия и неизменность
ручной загрузки Linux. GUI-тест проверяет состояния карточки в настоящем
Electron с sandbox.

Перед выпуском проверить обновление между двумя установленными сборками
через тестовый HTTPS feed: сохранение входа/Insights, скачивание по blockmap,
повтор после сетевой ошибки, UAC для установки в Program Files и фактический
запуск новой версии. Этот сценарий не заменяется unit-тестами.
