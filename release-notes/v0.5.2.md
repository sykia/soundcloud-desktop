# SoundCloud Desktop 0.5.2

Исправлена кнопка «Установить и перезапустить» для пакетов Linux. Установка запускается без shell, интерфейс остаётся отзывчивым и ждёт результата пакетного менеджера. Если права не получены или установка завершилась ошибкой, карточка показывает сообщение и ссылку на релиз.

### Установка

Для Windows и AppImage используйте встроенное обновление. Если в Linux установлена версия 0.5.0 или 0.5.1 и кнопка установки завершается ошибкой, скачайте пакет 0.5.2 ниже и установите его через пакетный менеджер один раз. Для Arch Linux: `sudo pacman -U ./soundcloud-desktop-0.5.2-1-x86_64.pkg.tar.zst`. После этого встроенная установка следующих версий будет использовать исправленный механизм.
