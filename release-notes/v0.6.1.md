# SoundCloud Desktop 0.6.1

Обновили панель cusade, добавили маленького спутника и исправили применение значков приложения.

## Изменения

- Исправлена смена значка закреплённого приложения Windows и ярлыка на рабочем столе при запуске из исходников: ярлыки сопоставляются по AppUserModelID. Для панели задач заданы параметры повторного запуска; добавлена проверка обоих стилей и ярлыков через реальный IPC.

- Исправлено применение стиля значка: PNG для окна и трея, системный значок панели задач Windows и пользовательская запись приложения Linux. Переключатели cusade двигаются через transform, предпросмотр ползунков обновляется раз в кадр.

- Настройки cusade упрощены: убраны рамки и подложки групп, добавлены плавные переходы между разделами и состояниями элементов с учётом настройки анимаций.

- Полностью переработаны настройки cusade: боковая навигация, пять разделов, светлая и тёмная темы с сохранением выбора, адаптивная компоновка. Способ открытия не изменился.

- Спутника можно бросить резким движением: инерция, гравитация, отскок от краёв и приземление на видимые элементы страницы. При прокрутке он следует за опорой, при её исчезновении падает.

- Добавлен маленький спутник cusade: прогулки, восемь поз, реакция на музыку и тихие звуки по нажатию. Персонаж и звуки отключаются отдельно в настройках. Его можно перетаскивать с сохранением места; он замечает курсор, реагирует на внимание и гуляет рядом с выбранным местом.

- Скрыты горизонтальная и вертикальная полосы прокрутки основной страницы; прокрутка колёсиком, тачпадом и клавиатурой сохраняется.

## Установка и обновление

- **Windows x64:** `SoundCloud-Desktop-Setup-0.6.1-x64.exe`. Закройте клиент и установите поверх существующей версии. Настройки и вход сохраняются. В версии 0.6.0 и новее обновление загружается автоматически; примените его через «Перезапустить и обновить». Старый клиент также может предложить обновление через меню трея.
- **Debian / Ubuntu / Mint:** `sudo apt install ./soundcloud-desktop_0.6.1_amd64.deb`.
- **Fedora:** `sudo dnf install ./soundcloud-desktop-0.6.1-1.x86_64.rpm`; **openSUSE:** `sudo zypper install ./soundcloud-desktop-0.6.1-1.x86_64.rpm`.
- **Arch / Manjaro:** `sudo pacman -U ./soundcloud-desktop-0.6.1-1-x86_64.pkg.tar.zst`.
- **Другие Linux x86_64:** `chmod +x SoundCloud-Desktop-0.6.1-x86_64.AppImage`, затем запустите файл. При отсутствии FUSE попробуйте `--appimage-extract-and-run`.
- **NixOS x86_64:** в исходниках выполните `npm ci`, затем `npm run install:nixos -- 0.6.1`. Требуются Node.js и Nix; используется отдельный пользовательский профиль. Если клиент уже установлен через этот профиль, доступно обновление через Nix внутри приложения.

`SHA256SUMS` содержит контрольные суммы файлов релиза. `latest.yml`, `latest-linux.yml` и Windows `.blockmap` нужны автообновлению; вручную запускать их не нужно.


## Примечания

Спутник и его звуки отключаются отдельно в cusade; положение и тема панели сохраняются. Windows-установщик не подписан сертификатом издателя. Доступны Windows x64 и Linux x86_64.
