# Если Windows отказала в доступе к установщику

Откройте папку «Загрузки» через Проводник и проверьте, остался ли в ней скачанный EXE. Если файл исчез, откройте «Безопасность Windows → Журнал защиты» и посмотрите запись за время запуска. Для обращения в поддержку пригодятся название события и имя файла.

Если файл на месте, откройте PowerShell в его папке и проверьте копию релиза 1.0.0:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\SCrip-1.0.0-Windows-x64.exe'
```

Ожидаемая сумма: `b85a63d988f183d3c357e20b5cec88badb9ef058cc3c768dc98087d1a190ab7f`. При несовпадении скачайте файл заново со страницы релиза. При совпадении и повторной ошибке укажите, появляется ли она до выбора установки, и приложите соответствующее событие защиты. На управляемом ПК администратор может проверить политику запуска по имени файла и времени события.

## Для сборки с подписью

В Windows откройте терминал с SignTool из Windows SDK и укажите отпечаток доверенного сертификата издателя для подписи кода и адрес его службы меток времени:

```powershell
python packaging/windows/package.py payload build/SCrip-Setup-x64.exe --sign-certificate $env:SCRIP_CERT_SHA1 --timestamp-url $env:SCRIP_TIMESTAMP_URL
```

Упаковщик подписывает копию приложения до упаковки, затем подписывает готовый установщик и проверяет обе подписи. Закрытый ключ остаётся у издателя. Релиз 1.0.0 опубликован без подписи.
