# SoundCloud Desktop 0.4.3

В этой версии код клиента разделён на модули основного процесса Electron, preload и общих настроек. Сборка preload теперь выполняется перед запуском и созданием установщиков; проверка проекта также проверяет связи между модулями.

Анимации cusade охватывают больше разделов SoundCloud: настройки, студию артиста, загрузку, подписки, уведомления, сообщения и медиатеку. Русский перевод расширен на большинство элементов интерфейса в этих разделах, меню и сообщениях. Названия треков, исполнителей и другой пользовательский текст не переводятся.

### Установка

Скачайте файл для своей системы на странице релиза: `.exe` для Windows, `.AppImage`, `.deb`, `.rpm` или `.pkg.tar.zst` для Linux. Если установлена версия 0.4.0 или новее, обновление можно открыть из уведомления приложения или через меню значка в трее. При первой установке системного пакета используйте менеджер пакетов своего дистрибутива.
