# Русская локализация SoundCloud

В приложении работают три слоя: контекстный каталог, словарь с правилами для
чисел и времени, затем локальный Bergamot для новых надписей. Каталог в
`shared/localization-catalog.json` учитывает язык источника, страницу и роль
элемента. Проверенные записи применяются раньше словаря и машинного перевода.

Выбор языка на сайте SoundCloud сохраняется. Если пользователь выбрал русский
язык приложения, переводится фактический интерфейс сайта — английский,
итальянский или испанский. При расхождении `<html lang="en">` с cookie сайта
используется cookie; известные строки дополнительно распознаются по каталогу
другого языка. Приложение не меняет `sclocale` и не экспортирует cookie.

Классификатор учитывает связь подписи с формой, переключателем, меню и областью
страницы. Ссылки на треки и профили, имена, описания, комментарии, сообщения и
компоненты cusade защищены до обращения к каталогу или Bergamot. Однословные
подписи допустимы для резервного перевода только в подтверждённом контексте
интерфейса; неоднозначные узлы остаются без изменений и попадают в аудит.
Запоздалые ответы переводчика не применяются после смены языка либо
восстановления оригинала. У `<option>`
сохраняется исходное значение формы. Для динамических подписей каталог
использует `{user}` и `{count}`: подставляется исходная строка, без перевода
имени или фиксации конкретного числа.

Загрузка и Artist Studio (`/artists`) открываются SoundCloud внутри `webi`
iframe. Основной preload туда не попадает. Главный процесс внедряет в этот
документ только DOM-обработчик без Node и Electron API; он использует тот же
классификатор, а каталог, словарь и локальный Bergamot применяются пакетами.
Обработчик наблюдает изменения DOM и восстанавливает исходные строки при
отключении русского. Включать Node в дочерних фреймах не требуется.

## Обновление каталога

1. В графической сессии с доступом к SoundCloud запустите
   `npm run localization:capture`. Сборщик использует открытое приложение и его
   текущую авторизованную сессию. Он запрашивает аудит у того же preload,
   который выполняет перевод, и возвращает исходную страницу после обхода.
   Кандидаты с подтверждённым контекстом интерфейса пишутся в
   `/tmp/soundcloud-labels.jsonl`, статусы страниц — в соседний файл
   `.report.json`. Для каждого раздела указаны обнаруженные, переведённые,
   оставшиеся, неоднозначные и защищённые элементы, машинные переводы, а также
   причины каждого пропуска без сохранения текста личных сообщений и имён.
   Несовпадение маршрута, отсутствие признаков раздела и отсутствие ответа
   preload помечаются отдельно. Для видимого `webi` iframe отчёт считает его
   DOM вместо оболочки страницы. Меню и переключение русского проверяются
   после взаимодействия; `/studio` как ошибочная страница не засчитывается за
   Artist Studio.
2. Запустите
   `npm run localization:generate -- /tmp/soundcloud-labels.jsonl`.
   По умолчанию генератор работает офлайн: берёт проверенные переводы каталога
   и словаря, приводит имена и счётчики к шаблонам и пишет предложения в
   `shared/localization-candidates.json`. С флагом `--draft` локальный
   Bergamot готовит черновики новых строк. Черновики помечаются
   `needs-context-review` и не включаются в поставляемый каталог без проверки
   смысла: наличие кириллицы само по себе не доказывает качество.
3. После просмотра предложений выполните ту же команду с `--write`.
   Повторный запуск заменяет запись с тем же языком, текстом, страницей и ролью,
   а не создаёт дубль. Для исправления конкретных записей можно передать
   `--reviewed /path/entries.json --write`.
4. По желанию при подготовке релиза можно запросить AI-варианты с `--api`
   и `OPENAI_API_KEY`. Это **явный платный режим**: отдельный проход создаёт,
   второй проверяет перевод, а результат проходит локальную проверку
   сохранения продуктов, чисел и переменных. Приложение пользователя не делает
   таких запросов и не требует ключа. Генератор повторно оценивает даже уже
   существующие записи, чтобы улучшенные переводы заменяли старые.
5. Запустите `npm run check && npm test`. Удалите временный файл наблюдений,
   если он больше не нужен. Не кладите профиль или файлы cookie в репозиторий.

Названия языков в настройках генерируются офлайн из локальных данных ICU
командой `node scripts/generate-language-names.js`; готовая карта поставляется
в приложении. Неоднозначные описания и материалы пользователей могут остаться
на исходном языке, если их нельзя надёжно отличить от интерфейса. Число
`machineTranslated` в отчёте показывает, сколько переводов ещё требуют
контекстной проверки, даже когда кириллица уже отображается.

## Состояние проверки

Последний доступный прогон реального приложения подтвердил перевод внутри
видимого iframe загрузки: 26 из 26 обнаруженных элементов интерфейса. В
Artist Studio были переведены 37 из 37; ещё 19 элементов классифицированы как
неоднозначные. На основной странице настроек были переведены 97 из 100
обнаруженных элементов. Эти числа показывают только обнаруженные элементы и
не означают полного охвата страниц или естественности машинных переводов.

После исправления выбора iframe и перевода девяти оставшихся подписей
повторный аудит `/artists` выполнен в графической сессии 8 октября 2026 года.
Проверка видимого экрана подтвердила отображение кириллицы. Открытые
меню, модальные окна и неоднозначные описания требуют отдельной контекстной
проверки: цифра 37 из 37 относится только к распознанным элементам интерфейса.
