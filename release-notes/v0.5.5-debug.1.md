# SoundCloud Desktop 0.5.5-debug.1

Диагностический релиз с исправлениями анимаций и установкой для NixOS.

- Исправлено включение анимаций в cusade: переключатель сохраняется, уже загруженные карточки получают эффекты. Переходы между страницами обнаруживаются из основного процесса Electron. Длительности и стиль эффектов сохранены.
- Исправлены русские подписи главной страницы при итальянском языке аккаунта и обновление перевода после изменения текста. Русская шапка адаптируется к ширине окна.
- «Скрыть Artist tools» также скрывает предложения Go+ и Artist Pro, освобождая место для поиска.
- NixOS использует отдельный пользовательский профиль Nix, проверку SHA256 релиза и запуск через FHS-обёртку. Обновление не пытается записывать в неизменяемый Nix store. Автозапуск использует постоянный путь запуска.
- Добавлены проверки настоящего sandboxed preload в Electron на Linux и Windows: анимации, русский интерфейс, скрытие предложений и блокировка аудиорекламы.

## Установка

Windows, Arch, DEB/RPM и AppImage: установите соответствующий файл релиза обычным способом.

NixOS x86_64: в исходниках выполните `npm ci`, затем `npm run install:nixos -- 0.5.5-debug.1`. Нужны Node.js и Nix. Приложение появится в меню; настройки и вход в аккаунт сохраняются. Следующие обновления устанавливаются кнопкой «Обновить через Nix» в приложении. Системная конфигурация и основной профиль Nix не изменяются.

Для разработки на NixOS: `nix-shell`, затем `npm ci`, `npm run electron:install` и `npm start`.

Откат пользовательского профиля: `nix-env --profile "$HOME/.local/share/soundcloud-desktop/nix/profile" --rollback` (при собственном XDG_DATA_HOME используйте его). Затем перезапустите приложение.
