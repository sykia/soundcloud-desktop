# Проверка прокрутки на Linux

Автоматический сценарий: `npm run check`, `npm test`, затем
`xvfb-run --auto-servernum npm run test:ui`. Существующий workflow
`.github/workflows/check.yml` выполняет его на Ubuntu и Windows.

GUI-тест проверяет pixel/line/page wheel, достижение конечной позиции,
горизонтальные жесты, Ctrl+колесо, вложенные области, reduced motion,
возврат назад/вперёд, отложенную загрузку списка и отмену восстановления
действиями пользователя. События колеса синтетические; это не проверка
драйвера мыши или физического тачпада.

Ручная проверка на машине Linux, отдельно в X11 и Wayland:

- Запустить `npm start` и проверить обычное колесо, быструю прокрутку,
  смену направления и остановку кликом/клавишей.
- Проверить тачпад: короткие и инерционные жесты двумя пальцами,
  горизонтальную прокрутку карусели, диагональные жесты и pinch-to-zoom.
- Проверить прокрутку cusade, выпадающих списков и модальных окон.
- Повторить с выключенными анимациями и с включённым соблюдением
  системного уменьшения движения.
- Повторить с масштабом страницы 100%, 125%, 150%.
- Прокрутить ленту, открыть трек и вернуться назад; повторить вперёд/назад.
  Проверить медленную подгрузку и ручную прокрутку сразу после возврата.

Позиции сохраняются в памяти текущего документа для последних 60 URL.
После перезапуска они не восстанавливаются. Если сайт за 5 секунд не
подгрузил достаточную высоту списка, восстановление прекращается на
доступной позиции; интерфейс не блокируется.

Статус локальной проверки: Windows GUI-тесты пройдены. Linux/WSL на
машине разработки отсутствует; X11, Wayland и физический тачпад не
проверены. Автоматические проверки Linux выполняются в GitHub CI; их результат
следует смотреть в Actions для конкретного коммита релиза.
