# SoundCloud Desktop 0.4.0

В cusade появился переключатель «Анимации». Он добавляет плавные реакции обложек, карточек, кнопок и меню, а также анимации панелей cusade и Insights. При смене трека название, обложка и волна в визуализации мягко сменяются; прогресс воспроизведения движется плавнее. Настройка выключена по умолчанию и сохраняется между запусками. При системном уменьшении движения новые эффекты отключаются.

Обновления теперь управляются через карточку внутри приложения. Когда доступна новая версия, приходит уведомление. Нажмите на него или выберите обновление в меню значка в трее, затем нажмите «Обновить». Карточка покажет ход загрузки и предложит «Установить и перезапустить». На Windows установщик может запросить разрешение администратора. Для DEB, RPM и pacman система запросит пароль через механизм повышения прав; AppImage обновляется без системного установщика. Если установка недоступна, в карточке есть ссылка на страницу релиза для ручного обновления. Загрузка и установка больше не запускаются автоматически при закрытии приложения.

### Установка

Скачайте установщик для своей системы на странице релиза: `.exe` для Windows, `.AppImage`, `.deb`, `.rpm` или `.pkg.tar.zst` для Linux. Для первой установки системного пакета используйте менеджер пакетов дистрибутива. Если уже установлена версия 0.4.0 или новее, следующие обновления можно запускать из карточки приложения. При переходе с 0.3.0 на 0.4.0 системные Linux-пакеты обновите вручную: прежняя версия показывает только ссылку на релиз.
