# SoundCloud Desktop 0.2.0

В этом выпуске добавлены обновления через GitHub Releases и сборки для большего числа дистрибутивов Linux.

### Добавлено

- Проверка обновлений при запуске, каждые шесть часов и вручную через меню в системном трее. Установщик Windows и AppImage загружают обновление автоматически; для системных Linux-пакетов приложение открывает страницу релиза.
- AppImage для дистрибутивов Linux x86_64, DEB для Debian/Ubuntu/Mint и RPM для Fedora/openSUSE. Пакет для Arch Linux и установщик Windows также доступны.
- Discord RPC: название трека, исполнитель, обложка и время воспроизведения. Используется общий ID cusade; свой Application ID можно указать в настройках.
- Автозапуск при входе в Windows и Linux, в том числе свёрнутым в трей.
- Скрытие баннера «События рядом» и аудиорекламы в настройках cusade.
- Открытие ссылок SoundCloud внутри приложения и отдельная ссылка-схема `soundcloud-desktop://` для внешних программ.

### Исправлено

- Закрытие окна больше не останавливает музыку: приложение остаётся в трее до команды «Выход».
- При ошибке разрешения имени приложение пробует Cloudflare и Quad9 после Google. Добавлены тайм-ауты, конечное число попыток и код ошибки на странице повтора.
- Повторный запуск открывает уже работающее окно.

### Установка

- `SoundCloud-Desktop-Setup-0.2.0-x64.exe` — Windows x64, запустите установщик.
- `SoundCloud-Desktop-0.2.0-x86_64.AppImage` — Linux x86_64, выполните `chmod +x` и запустите файл.
- `soundcloud-desktop_0.2.0_amd64.deb` — Debian, Ubuntu, Mint: `sudo apt install ./soundcloud-desktop_0.2.0_amd64.deb`.
- `soundcloud-desktop-0.2.0-1.x86_64.rpm` — Fedora: `sudo dnf install ./soundcloud-desktop-0.2.0-1.x86_64.rpm`; openSUSE: `sudo zypper install ./soundcloud-desktop-0.2.0-1.x86_64.rpm`.
- `soundcloud-desktop-0.2.0-1-x86_64.pkg.tar.zst` — Arch Linux: `sudo pacman -U ./soundcloud-desktop-0.2.0-1-x86_64.pkg.tar.zst`.

Файл `SHA256SUMS` содержит контрольные суммы. Установщик Windows не подписан цифровым сертификатом. Для работы нужен интернет и доступ к SoundCloud.
