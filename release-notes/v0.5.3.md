# SoundCloud Desktop 0.5.3

Русский язык переработан: интерфейс SoundCloud переводится автоматически по мере появления новых надписей. Приложение определяет язык страницы и использует локальные модели для английского, итальянского и испанского. Известные кнопки и пункты меню переводятся сразу; названия треков, имена артистов и комментарии остаются исходными. Текст не отправляется в облачный переводчик. Машинный перевод отдельных новых фраз может быть неточным.

В релиз также входят исправления обновления и анимаций Windows из 0.5.0 и установки обновлений Linux из 0.5.2.

### Установка

Откройте карточку обновления в приложении и нажмите «Обновить», затем «Установить и перезапустить». Для первой установки скачайте `.exe` для Windows или пакет своего дистрибутива Linux ниже. Если в старой версии кнопка установки Linux-пакета выдаёт ошибку, скачайте пакет 0.5.3 и установите его через пакетный менеджер один раз.
