# SoundCloud Desktop 0.6.0

Стабильный релиз для Windows x64 и Linux x86_64: плавная прокрутка, возврат в ленту, меньше лишней работы в фоне и автоматическая загрузка обновлений Windows.

## Изменения

- Исправлена очистка временных `.part`-файлов при неудачном скачивании, выявленная Linux CI. Существующий файл сохраняется при ошибке загрузки.

- При включённых «Анимациях» добавлены мягкая инерция колеса мыши и плавное появление карточек снизу. Вложенные области и Ctrl+колесо сохраняют обычное поведение. Можно учитывать системное уменьшение движения.
- «Назад/Вперёд» восстанавливает позицию страницы в текущей сессии, ожидая подгрузку списка до 5 секунд. Ручная прокрутка отменяет восстановление.
- В скрытом и свёрнутом окне приостанавливаются визуальные периодические задачи и наблюдатель скачиваний. Музыка, Insights и Discord продолжают работу. После возврата кнопки скачивания восстанавливаются; в видимой ленте сканируются изменённые участки вместо всей страницы.
- Перевод iframe очищает ссылки на отсоединённые DOM-элементы, уменьшая риск накопления памяти.
- Windows автоматически загружает найденное обновление в фоне. В cusade появилась проверка обновлений; карточка показывает прогресс, ошибку и повторную попытку. Применение — через «Перезапустить и обновить», без мастера установки. Обычный выход не запускает установку. При невозможности дифференциальной загрузки скачивается полный пакет.
- Включены исправления диагностической 0.5.5-debug.1: русский интерфейс, переключение анимаций, скрытие Artist tools и управляемая установка/обновление NixOS.
- Расширены тесты настоящего sandboxed preload: прокрутка, история навигации, фоновое состояние, динамические кнопки и карточка обновления. Добавлены тесты контроллера обновлений.

## Установка и обновление

- **Windows x64:** `SoundCloud-Desktop-Setup-0.6.0-x64.exe`. Закройте клиент и установите поверх существующей версии. Настройки и вход сохраняются. Со следующего релиза действует автоматическая фоновая загрузка, добавленная в этой версии. Старый клиент также может предложить обновление через меню трея.
- **Debian / Ubuntu / Mint:** `sudo apt install ./soundcloud-desktop_0.6.0_amd64.deb`.
- **Fedora:** `sudo dnf install ./soundcloud-desktop-0.6.0-1.x86_64.rpm`; **openSUSE:** `sudo zypper install ./soundcloud-desktop-0.6.0-1.x86_64.rpm`.
- **Arch / Manjaro:** `sudo pacman -U ./soundcloud-desktop-0.6.0-1-x86_64.pkg.tar.zst`.
- **Другие Linux x86_64:** `chmod +x SoundCloud-Desktop-0.6.0-x86_64.AppImage`, затем запустите файл. При отсутствии FUSE попробуйте `--appimage-extract-and-run`.
- **NixOS x86_64:** в исходниках выполните `npm ci`, затем `npm run install:nixos -- 0.6.0`. Требуются Node.js и Nix; используется отдельный пользовательский профиль. Если клиент уже установлен через этот профиль, доступно обновление через Nix внутри приложения.

`SHA256SUMS` содержит контрольные суммы файлов релиза. `latest.yml`, `latest-linux.yml` и Windows `.blockmap` нужны автообновлению; вручную запускать их не нужно.

## Ограничения

- Windows-установщик не подписан сертификатом издателя. Полный цикл обновления между двумя установленными версиями нового контроллера отдельно не подтверждён.
- Сборки ARM64/32-bit/macOS не включены. Нет гарантии работы на каждом дистрибутиве Linux. Реальные Wayland/X11, физический тачпад и NixOS требуют отдельной ручной проверки.
- Длительное сопоставимое профилирование не завершено: процент ускорения и отсутствие утечек не заявляются.
- SoundCloud — сторонний изменяющийся сайт. Доступность воспроизведения зависит от аккаунта, региона и сети. Клиент не является официальным продуктом SoundCloud.
