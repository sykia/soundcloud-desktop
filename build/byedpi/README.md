# ByeDPI 0.17.3

Источник и лицензия MIT: https://github.com/hufrea/byedpi/releases/tag/v0.17.3

Включены оригинальные бинарные файлы из официальных архивов релиза:

- `win32-x64/ciadpi.exe` из `byedpi-17.3-x86_64-w64.zip`.
- `linux-x64/ciadpi-x86_64` из `byedpi-17.3-x86_64.tar.gz`.

SHA256 архивов сверены с GitHub Release API. SHA256 архивов и исполняемых файлов
зафиксированы в `shared/byedpi.json`. `npm run verify:byedpi` проверяет файлы
перед упаковкой; клиент также проверяет свой файл перед запуском.

Бинарные файлы поставляются вместе с приложением. Скачивание при первом запуске,
установка службы, драйвера и права администратора для обхода не требуются.
Служебные BAT-файлы исходного архива намеренно не включены.
