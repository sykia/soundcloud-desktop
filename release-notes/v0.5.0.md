# SoundCloud Desktop 0.5.0

- Удалена функция переноса музыки вместе с настройками и сетевым импортом.
- Обновление Windows запускается в текущем каталоге без повторного мастера установки. Поддерживается дифференциальная загрузка NSIS.
- Исправлены анимации cusade при включённом в Windows уменьшении движения, если в cusade выключен учёт этой системной настройки.
- Значок окна и трея можно переключать между официальными вариантами Cloudmark: чёрным на оранжевом и белым на чёрном.
- Исправлена работа русского словаря и перевода пунктов выбора.

### Установка

Скачайте `.exe` для Windows или `.AppImage`, `.deb`, `.rpm`, `.pkg.tar.zst` для Linux ниже на странице релиза. Ручная установка нужна только при первом запуске или если встроенное обновление не удалось.
