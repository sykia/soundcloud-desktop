# Скачивание треков

Кнопка cusade появляется рядом с действиями на странице трека и в списках SoundCloud. Она сохраняет доступный для текущего аккаунта MP3 или M4A через API и медиасерверы SoundCloud. Если SoundCloud не выдаёт аудиопоток, приложение сообщает об ошибке. Подписка Go+ по-прежнему требуется для HQ; кнопка не повышает качество обычного потока.

Расположение кнопки и порядок запроса аудиопотока основаны на открытом проекте [SoundCloud Downloader](https://github.com/NotTobi/soundcloud-dl) автора NotTobi. Проект распространяется по [лицензии MIT](https://github.com/NotTobi/soundcloud-dl/blob/master/LICENSE). Код расширения и его зависимости в приложение не включены.
