# SoundCloud Desktop 0.4.2

Исправляющий релиз после 0.4.1: анимации в приложении стали плавными и перестали подтормаживать, в том числе на Windows. Возвращено штатное аппаратное ускорение, поэтому интерфейс больше не выглядит застывшим; на видеокарте, которая действительно не справляется, приложение само перейдёт в безопасный программный режим. Переключатель анимаций теперь работает независимо от системной настройки уменьшения движения — учитывать её можно отдельной настройкой в панели cusade. Плавные реакции интерфейса сохранены, добавлены мягкие переходы между страницами SoundCloud.

### Установка

Скачайте установщик для своей системы на странице релиза: `.exe` для Windows, `.AppImage`, `.deb`, `.rpm` или `.pkg.tar.zst` для Linux. Если установлена версия 0.4.0 или новее, новую версию можно установить из карточки обновления в приложении. Для первой установки системного пакета используйте менеджер пакетов дистрибутива.
