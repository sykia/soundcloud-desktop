# Подключение и диагностика сети

Приложение работает в сетях с ограниченной доступностью SoundCloud: оно
показывает понятную ошибку загрузки, позволяет выбрать режим подключения
и провести проверку соединения из cusade-панели.

## Режимы подключения

- **Системный прокси (по умолчанию, `system`)** — сеанс Electron использует
  системные настройки Windows. Приложение не меняет и не сохраняет их.
- **Без прокси (`direct`)** — весь трафик идёт напрямую, прокси сеанса
  отключён.
- **Свой прокси (`custom`)** — пользователь указывает тип (`http`, `https`,
  `socks4`, `socks5`), хост и порт. `ses.setProxy({ mode: 'fixed_servers', …
  proxyBypassList: '<local>' })` покрывает все HTTP-запросы сеанса, включая
  поток и API. Имя пользователя и пароль не хранятся в открытом виде:
  шифрование выполняет `safeStorage` (DPAPI в Windows); при сбросе настроек
  сохранённые данные очищаются.

Пустые поля имени и пароля не удаляют сохранённые учётные данные — так
случайное открытие панели не разлогинивает прокси. Чтобы удалить их, нажмите
«Сбросить».

Проверки при старте: если сохранённая конфигурация `custom` неполная,
приложение продолжает работу в режиме `system` и сообщает об этом в статусе
сети. Неприменимая конфигурация откатывается к предыдущей исправной с
закрытием соединений.

HTTP 401/403 трактуется как «доступ ограничен в этой сети»: это не
доказательство блокировки провайдером и не признак неисправности
транспорта — DNS, TCP и TLS при таком ответе уже работают.

## Когда появляется экран ошибки

Если загрузка страницы SoundCloud завершилась ошибкой, приложение показывает
локальный экран (это HTML, сгенерированный приложением, без сетевых
запросов и без IPC), в котором виден тип сбоя и кнопки: проверить
подключение и открыть настройки сети. DNS-ротация сохраняет прежнее
поведение (перебор DoH-адресов при ошибках резолвинга).

Классификация ошибок находится в `shared/network-profile.js`:
`classifyNetworkError` распознаёт DNS-коды, TLS-коды `ERR_CERT_*`/SSL,
тайм-ауты (включая собственные тайм-ауты зондов вида
`net::ERR_…_TIMED_OUT`), TCP-отказы и туннельные ошибки прокси;
`classifyHttpStatus` сортирует HTTP-ответы. Ошибка содержит только
`net::ERR_*`-категорию и имя шага — без URL и личных данных.

## Проверка подключения

Кнопка «Проверить подключение» (панель, раздел «Сеть», и экран ошибки)
запускает три шага через IPC `cusade:network:…`:

1. **dns** — `ses.resolveHost('soundcloud.com')` с тайм-аутом 8 с. Пустой
   список адресов при отсутствии ошибки не считается сбоем: окончательным
   критерием являются HTTP-зонды.
2. **html** — `net.fetch('https://soundcloud.com/')`, тело ответа не
   читается, тайм-аут 8 с. Любой HTTP-статус означает, что транспорт
   работает; 401/403 показываются как «ограниченный доступ».
3. **api** — тот же зонд для `https://api-v2.soundcloud.com/`.

Проверка выполняется один раз, автоматически не повторяется. Пока проверка
не запускалась, статус показывает «Проверка соединения не выполнялась».

## Наблюдение за трафиком

`startTrafficObservation` считает через `ses.webRequest` ошибки и ответы
query по категориям html/api/media. Хранятся счётчики, фаза и тип (например
`html:tcp`), не более 60 последних событий — без URL, заголовков и тела
ответа. Отдельно фиксируется последняя загрузка главной страницы (`recordPageLoad`)
и отражается в статусе.

## Отчёт

Кнопка «Сохранить отчёт» экспортирует JSON через системный диалог:

- версия приложения/Electron/платформа, режим сети и тип прокси, DNS-провайдер,
  состояние online;
- результат последнего ручного главным страница загрузки и последней проверки;
- счётчики и события по категориям с отметками времени.

Отчёт не содержит cookies, токенов, заголовков Authorization, URL с
параметрами, данных форм и содержимого ответов. Хост и порт
своего прокси в отчёт входят, поскольку это конфигурация пользователя,
а не секрет; учётные данные в отчёт не попадают никогда.

## Границы и ограничения

- Приложение не включает и не выключает системный VPN и не меняет настройки
  Windows; публичные прокси автоматически не подставляются.
- Обход блокировок не входит в задачи: поддержка настроек узла,
  выбранного пользователем, — это только стандартные настройки сети.
- Порт прокси ограничен 1–65535, хост — имя без схемы и параметров.
- Страница SoundCloud по-прежнему может отклониться от ожиданий при новой
  версии сайта; экран ошибки отражает только транспортную часть загрузки.

## Проверки

- `npm test` — 24 модульных теста с заменой Electron (валидация настроек,
  классификация, применённый с откатом, безопасность IPC, экран ошибки).
- `npm run test:network` — Electron-интеграционный стенд с локальными
  серверами: TLS-зонд на plain-HTTP, зависший сервер, `.invalid`, переход
  в режим custom через настоящий `setProxy`, экран ошибки при
  `ERR_PROXY_CONNECTION_FAILED`, отказ каналов незашаженного окна.
- `npm run check` и `npm run test:ui` — обычные проверки консистентности и
  cusade-панели (раздел «Сеть» входит в смок-счётчик).
