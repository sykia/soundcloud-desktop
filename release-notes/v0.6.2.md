# SoundCloud Desktop 0.6.2

- Автоподбор расширен до 12 профилей: разделение в середине SNI, несколько
  фрагментов, обратная отправка с OOB, поддельные пакеты, поддельный TLS и
  совместимость TLS. Действующее VPN-подключение приложение не отключает.

- Добавлен бесплатный встроенный обход DPI для Windows x64 и Linux x64.
  Ничего дополнительно устанавливать и настраивать не нужно.
- При сетевых сбоях клиент автоматически перебирает способы подключения,
  меняет защищённый DNS и повторяет попытки с паузами до восстановления связи.
  Рабочая стратегия сохраняется между запусками.
- В cusade → «Приложение» доступны состояние подключения и режимы
  «Автоматически», «Усиленный обход», «Напрямую». Меню «Подключение» (Alt)
  доступно также при незагрузившемся сайте.
- Добавлены повторная загрузка страницы после восстановления сети и попытка
  восстановления плеера с сохранением позиции после сетевой ошибки.

## Установка и обновление

- Windows x64: установите `SoundCloud-Desktop-Setup-0.6.2-x64.exe` поверх
  предыдущей версии либо примените штатное обновление. Настройки и вход сохраняются.
- Debian/Ubuntu: `sudo apt install ./soundcloud-desktop_0.6.2_amd64.deb`.
- Fedora: `sudo dnf install ./soundcloud-desktop-0.6.2-1.x86_64.rpm`.
- Arch/Manjaro: `sudo pacman -U ./soundcloud-desktop-0.6.2-1-x86_64.pkg.tar.zst`.
- Остальные Linux x86_64: разрешите запуск `SoundCloud-Desktop-0.6.2-x86_64.AppImage`
  и откройте его. При отсутствии FUSE используйте `--appimage-extract-and-run`.
- NixOS: `npm run install:nixos -- 0.6.2` из исходников.

ByeDPI включён в приложение под лицензией MIT. VPN, подписки, собственные
серверы и загрузка компонента при первом запуске не требуются.
Система не меняет внешний IP и не гарантирует обход блокировки по IP или
ограничений контента SoundCloud. Проверка на сетях российских операторов
проводится пользователем; работоспособность у всех провайдеров пока не подтверждена.
