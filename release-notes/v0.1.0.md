Первый выпуск SoundCloud Desktop.

В приложении есть визуализация текущего трека на главной, случайное воспроизведение лайков, настройки цвета и скругления, скрытие Artist tools и русский язык. Панель cusade и кнопка «Мои лайки» работают в светлой и тёмной темах.

**Скачать:**

- `soundcloud-desktop-0.1.0-1-x86_64.pkg.tar.zst` — Arch Linux и совместимые системы. Установка: `sudo pacman -U ./soundcloud-desktop-0.1.0-1-x86_64.pkg.tar.zst`. Приложение появится в меню программ.
- `SoundCloud-Desktop-Setup-0.1.0-x64.exe` — установщик Windows x64. После установки приложение появится в меню «Пуск»; значок на рабочем столе создаётся установщиком.

Файл `SHA256SUMS` содержит контрольные суммы загрузок. Установщик Windows не подписан цифровым сертификатом. Для работы приложения нужен интернет и доступ к SoundCloud.
